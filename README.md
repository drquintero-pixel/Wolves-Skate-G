# Wolves Skate

## Estructura

```text
mi pagina web/
├── index.html
├── styles.css
└── imagenes/
    ├── a1.jpeg
    ├── WhatsApp Image 2026-10-21 at 2.00.42 PM.jpeg
    ├── WhatsApp Image 2026-10-22 at 8.30.31 AM.jpeg
    ├── descarga (1).jpeg
    ├── descarga.jpeg
    ├── images (1).jpeg
    └── images.jpeg
```

- `index.html`: contenido, navegación, formulario y referencias a imágenes, fuentes e íconos.
- `styles.css`: identidad visual, componentes y reglas responsivas.
- `imagenes/`: recursos locales del club. Conserva esta carpeta junto a `index.html`.

Abre `index.html` en un navegador para revisar la página. Las fuentes, los íconos, el video y algunas fotos requieren conexión a internet.

Para GitHub Pages, sube `index.html`, `styles.css` y la carpeta `imagenes/` al mismo nivel (raíz) del repositorio. Las rutas locales usan `./styles.css` y `./imagenes/...`, por lo que funcionan también bajo la ruta del repositorio. El video se carga desde YouTube mediante el iframe de `youtube-nocookie.com`; no hay un archivo de video local que subir.

## Antes de publicar

- Confirma el número de WhatsApp, las cuentas de redes sociales, dirección y horarios.
- Reemplaza el video de referencia y actualiza las cifras y testimonios de muestra por información real autorizada.
- El formulario usa `mailto:`; para recibir solicitudes directamente desde la web, conéctalo a un servicio de formularios.
